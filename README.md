# रक्तसेतू (Rakthasetu) — Blood Bridge

कोपरगाव व परिसरासाठी **रक्ताची निकड व रक्तदानाचे मोफत ॲप**.

🔴 **कोणतेही रक्तगट पाठवा → 1 मिनिटात WhatsApp वर ready-made message**
📱 **Installable PWA** — Android browser menu → “Add to Home screen”

## सुविधा
- रक्तगट पाठवून थेट WhatsApp वर त्वरित message (युनिट, रुग्णालय, संपर्क नंबर)
- माझ्या विनंत्या यादी — मजकूर सुरक्षित ठेवा, “रक्त मिळाले” असे कळवा
- रक्तदान डायरी (पुरुष ९० / महिला १२० दिवसांचे अंतर आपोआप गणना)
- पात्रतेची तपासणी (चेकलिस्ट)
- रक्तगटानुसार “कोणाला रक्त देऊ शकता / कोणाकडून घेऊ शकता” चार्ट
- श्री साईनाथ रक्तपेढी, शिर्डी (२४ तास) — थेट फोन कॉल
- इंटरनेटशिवाय काम करते (Service Worker)

## Run locally
Static folder — any web server works:
```bash
python -m http.server 8100
# open http://localhost:8100
```

## Deploy
Push to any static host with HTTPS (e.g. GitHub Pages) — no build step, zero dependencies.
